# Market My Art API

A comprehensive Laravel-based REST API for the **Market My Art** platform, built to power web and mobile applications for discovering, showcasing, and purchasing fine art and creative works.

---

## Features

- **Authentication & Authorization**: JWT/Sanctum-based authentication with role-based access control (Artists, Buyers, Admins)
- **Artwork Management**: Complete CRUD operations for artwork portfolios, pricing, and categorizations
- **Artist Profiles**: Artist bios, studio statements, social links, and custom portfolio management
- **Gallery & Exhibitions**: Virtual galleries, collection grouping, and exhibition tracking
- **Orders & Checkout**: Secure art purchasing, cart processing, and invoice generation
- **Inquiries & Commissions**: Direct messaging and custom commission requests between buyers and artists
- **Announcements & Press**: Platform updates, exhibitions, and featured artist announcements
- **Wishlist & Favorites**: Save and track favorite artworks and collections
- **Profile Management**: User profile updates, preferences, and avatar/banner uploads
